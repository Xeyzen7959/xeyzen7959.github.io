# Planetary surface maps

Source: [Solar System Scope textures](https://www.solarsystemscope.com/textures/), licensed under [Creative Commons Attribution4.0 International](https://creativecommons.org/licenses/by/4.0/). Solar System Scope creates these maps using NASA imagery and other scientific data; see the source page for individual details.

Original2k maps downloaded2026-10-29: Earth day/night/clouds, Mercury, Venus atmosphere, Mars, Jupiter, Saturn, Uranus, Neptune, Sun, Moon and Saturn ring alpha. Files are distributed unchanged. For mobile rendering only, the application downsamples decoded images to1024px before GPU upload.

The visualization exaggerates planet sizes, spacing and orbital speeds for navigation; it is not a scientific scale model.
