01 / AI KNOWLEDGE & SUPPORT

Sourcewell

A document knowledge workspace with source-linked answers and a path to human support.

SOURCEWELL / PRODUCT INTERFACEKNOWLEDGE, CONNECTED.Source
wellTHE IDEAAnswers, with
something behind them.

The idea

Help support teams answer questions from company documents, while keeping the source of each answer visible.

What I’m building

  • Document ingestion and a searchable knowledge workspace.
  • Hybrid retrieval with Chroma, BM25, and reciprocal rank fusion.
  • Structured answers with inspectable citations and a path to human handoff.

Built with

React · TypeScript · FastAPI · Chroma · BM25

Project notes

The project includes recorded examples, which are distinct from live AI responses. No live answer-quality benchmark has been run. The project preview is an actual interface image from the public repository.

03 / EMBEDDED SYSTEMS · IN DEVELOPMENT

ESPION

ESPION / HANDHELD CONCEPTESPION
ESPIONEXPLORE THE SIGNAL.
S3 / MODULAR EXPLORATION
ILLUSTRATIVE PROTOTYPE

The idea

A modular ESP32-S3 firmware project with a graphical interface for educational hardware experimentation.

Current direction

Exploring how embedded software and a compact visual interface can make hardware experiments more approachable. I’m developing the interface and modular foundation, with additional hardware modules on the roadmap.

Built with

C++17 · Arduino Framework · PlatformIO · LovyanGFX · ESP32-S3

Project notes

The preview is an illustrative handheld prototype with a short antenna, four directional controls, and the project’s purple interface. It is a product concept, not a photograph of a finished device. The interface image was supplied for this portfolio; displayed menu items do not imply completed hardware modules. See the public repository for the current implementation.
